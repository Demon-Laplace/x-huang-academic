# X.HUANG — Academic Homepage

A bilingual academic homepage for Xin Huang, a PhD student at LIRA, Observatoire de Paris.

[Visit the live homepage](https://demon-laplace.github.io/x-huang-academic/)

The site includes current Fornax research, previous and collaborative work, publications, academic background, and contact information. Use the EN / 中文 controls to switch languages.

## Publishing

GitHub Pages publishes the root of the `main` branch. The `.nojekyll` file keeps this plain HTML, CSS, and JavaScript site buildless. Assets use relative paths so the site works under a GitHub Pages project URL.

Edit `index.html` for content, `styles.css` for presentation, and `app.js` for language switching. Keep matching `data-en` and `data-zh` text when updating bilingual content. Push updates to `main` to publish them.
